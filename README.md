# Kanora Server

フォルダを選んでボタンを押すだけで、ローカルのWebサーバーを立ち上げられるデスクトップアプリです。
コマンドは要りません。Windows / macOS / Linux で動きます。

by **KanoraStudio**

> ⚠️ **初めて起動するとき、OSの警告が出ます。**
> Windowsの「SmartScreen」や、Macの「Macに損害を与える可能性があります」などの表示です。
> 理由と、開き方は → [**警告が出たときは**](#警告が出たときは)

---

## できること

- **ボタンで操作**: 起動・停止・再起動・ブラウザで開く
- **フォルダ / ファイルを選んで配信**: ドラッグ&ドロップにも対応（フォルダをドロップ → 配信フォルダに設定、ファイルをドロップ → 配信フォルダにコピー）
- **ファイル一覧**: 配信しているフォルダの中身をアプリ内で確認
- **IPアドレスを自動検出**: 同じネットワークの他の端末から開くためのURLを表示
- **空いているポートを自動で選択**: 8000番が使用中なら、空いている番号に切り替えます
- **CPU / RAM の使用状況**を表示
- **エラーの説明**: 何が起きたか・原因・対処方法を日本語で表示
- **アプリ内アップデート**: 「更新を確認」を押すだけで最新版に入れ替え

## ダウンロード

[**Releases**](https://github.com/KanoraStudio/ServerStartLaunch/releases/latest) から、お使いの環境に合うファイルをダウンロードしてください。

| 環境 | ファイル |
|---|---|
| Windows（Intel / AMD） | `KanoraServer-Windows-x64.exe` |
| Mac（Apple Silicon: M1 / M2 / M3 など） | `KanoraServer-macOS-arm64.dmg` |
| Mac（Intel） | `KanoraServer-macOS-x64.dmg` |
| Linux（x64） | `KanoraServer-Linux-x64.tar.gz` |

Windows と Linux の Arm64 版は、現在は配布していません。

どれを選べばいいか分からないときは、`KanoraServer-all.zip`（全部入り）がある場合はそちらを使えます。Macは、Appleメニュー →「このMacについて」で、チップの種類を確認できます。

**ダウンロードは、必ずこのページの Releases からしてください。** 他のサイトや、他の人から渡されたファイルは、中身が書き換えられている可能性があるので、使わないでください。

## インストールと最初の起動

### Windows

1. `KanoraServer-Windows-x64.exe` をダウンロードして、好きなフォルダに置きます（例: `C:\KanoraServer\`）。
2. ダブルクリックで起動します。
3. 警告が出たら、[下の手順](#windows-smartscreen) で開きます。

### macOS

1. `.dmg` を開いて、`KanoraServer.app` を **Applications** にドラッグします。
2. `Applications` の `KanoraServer.app` を開きます。
3. 警告が出たら、[下の手順](#macos-gatekeeper) で開きます。

### Linux

```bash
tar xzf KanoraServer-Linux-x64.tar.gz
chmod +x KanoraServer
./KanoraServer
```

画面が出ないときは、Tk（`libtk8.6`）が入っていない可能性があります。Ubuntu / Debian 系なら、次で入ります。

```bash
sudo apt install libtk8.6
```

## 警告が出たときは

### なぜ警告が出るの？

このアプリは、まだ**「署名」と「公証」をしていません**。署名とは、「このアプリは、この開発者が作った、改ざんされていないものです」とOSに証明する仕組みです。WindowsもMacも、署名のないアプリを、初めて起動するときに警告します。

署名には、有料の証明書や開発者登録が必要です。個人で作っているこのアプリは、まだ対応していません。

**警告が出ること自体は、アプリが危険だという意味ではありません。** OSが、「誰が作ったか確認できない」と言っているだけです。ただ、その分、**ダウンロード元が正しいか**を、自分で確認する必要があります。

- ✅ このリポジトリの [Releases](https://github.com/KanoraStudio/ServerStartLaunch/releases) からダウンロードしたファイルだけを使ってください。
- ❌ 他のサイト、メール、チャットなどで渡されたファイルは、開かないでください。

### <a id="windows-smartscreen"></a>Windows: SmartScreen の警告

起動すると、青い画面で次のように出ることがあります。

> **Windows によって PC が保護されました**
> Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。

開き方:

1. 画面の「**詳細情報**」をクリックします。
2. 下に出る「**実行**」ボタンを押します。

一度許可すると、次からは出ません。

**ブラウザでダウンロードするときの警告**

EdgeやChromeで、「このファイルは一般的にダウンロードされていません」などと出ることがあります。ダウンロード一覧の「…」から「**保存**」または「**保持する**」を選んでください。

**ウイルス対策ソフトに止められたとき**

このアプリは、Pythonのプログラムを1つのexeにまとめて作っています。この形式のアプリは、ウイルス対策ソフトに、**誤って危険と判定される**ことがあります。exeが消えたり、隔離されたりしたときは、ウイルス対策ソフトの隔離一覧から復元して、このアプリを「除外（許可）」に追加してください。公式のReleasesから入れたファイルだけを許可してください。

### <a id="macos-gatekeeper"></a>macOS: 「Macに損害を与える可能性があります」などの警告

Macでは、ゲートキーパーという機能が、署名のないアプリを止めます。表示される文章は、macOSのバージョンによって少し違います。

> 「KanoraServer」は、Macに損害を与える可能性のあるソフトウェアが含まれていないことをAppleが検証できないため、開けません。

> 「KanoraServer」は壊れているため開けません。ゴミ箱に入れる必要があります。

> 開発元を検証できないため、「KanoraServer」を開けません。

**どの表示でも、「ゴミ箱に入れる」は押さないでください。** 「キャンセル」または「完了」を押して、次のどれかを試します。

**方法A: システム設定から許可する（macOS 15 Sequoia 以降。まずこれを試す）**

1. 警告が出たら、「完了」を押して閉じます。
2. Appleメニュー →「**システム設定**」→「**プライバシーとセキュリティ**」を開きます。
3. 下のほうに、「"KanoraServer"はブロックされました」と出ています。「**このまま開く**」を押します。
4. パスワード（またはTouch ID）を入力して、「開く」を押します。

**方法B: 右クリックで開く（macOS 14 Sonoma 以前）**

1. `Applications` の `KanoraServer.app` を、**右クリック（Controlキー + クリック）**します。
2. メニューから「**開く**」を選びます。
3. 出てきた画面で、もう一度「**開く**」を押します。

**方法C: ターミナルで解除する（「壊れているため開けません」が出るとき）**

ダウンロードしたファイルに付く「インターネットから来た」という印を、外します。

```bash
xattr -cr /Applications/KanoraServer.app
```

そのあと、もう一度、通常どおり開いてください。

一度開ければ、次からは普通に起動できます。

### アプリ内アップデートで入れたときは？

アプリ内の「更新を確認」から入れ替えたときは、通常、これらの警告は出ません。警告が出るのは、**最初に、ブラウザなどでダウンロードしたときの1回だけ**です。

## 使い方

1. アプリを開きます（開いただけでは、サーバーは起動しません）。
2. **配信したいフォルダ**を選びます。次のどれでもOKです。
   - ファイル欄にフォルダをドラッグ&ドロップ
   - 「フォルダを選ぶ」でフォルダを選択
   - 「ファイルを選ぶ」でファイルを選択（そのファイルのあるフォルダを配信し、ブラウザではそのファイルが開きます）
3. 「**▶ 起動**」を押します。
4. 右側に表示された **URL** をクリック、または「ブラウザで開く」を押します。

### 他の端末から開きたいとき

右側の「設定」で、ホストを `0.0.0.0` にして起動します。同じWi-Fi / ネットワークにいる端末から、画面に出る `LAN:` のURLで開けます。

初回は、OSのファイアウォールが「受信接続を許可しますか」と聞いてきます。LAN内で使うなら、許可してください。

### 設定

| 項目 | 内容 |
|---|---|
| ホスト | 自動検出したIP / `0.0.0.0`（他の端末にも公開） / `127.0.0.1`（このPCだけ） |
| ポート | 最初は `8000`。使用中なら空いている番号に自動で変わります |
| フォルダ | 配信するフォルダ |
| キャッシュ無効 | ブラウザが古い内容を使わないようにします |
| CORS許可 | 別のページからのアクセスを許可します |
| アクセスログを出さない | ログ欄の表示を減らします |

設定は、サーバーが止まっているときだけ変更できます。

## アップデート

右下の「**アップデート**」欄で、「更新を確認」を押します。新しいバージョンがあると、「⬆ vX.Y.Z に更新する」に変わります。押すと、自動でダウンロードして入れ替え、アプリが再起動します。

- アプリ内の更新は、**配布版（exe / dmg / tar.gz）**でだけ動きます。
- アプリが書き込めない場所（例: dmgを開いたまま、中のアプリを起動している）では更新できません。`Applications` などにコピーしてから使ってください。
- 更新はこのリポジトリの [Releases](https://github.com/KanoraStudio/ServerStartLaunch/releases) を見に行きます。

## 簡易API

サーバーには、動作確認用のAPIが2つ付いています。

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/ping` | `{"ok": true, "time": ...}` を返します |
| POST | `/api/echo` | 送った内容をそのまま返します |

## 困ったとき

アプリの左下に「**エラーの説明**」欄があります。エラーが起きると、原因と対処方法がここに出ます。

| よくある症状 | 対処 |
|---|---|
| 起動すると警告が出て開けない | [警告が出たときは](#警告が出たときは) を見てください |
| 「▶ 起動」が押せない | 先にフォルダかファイルを選んでください |
| 他の端末から開けない | ホストを `0.0.0.0` にして、ファイアウォールを許可してください。端末が同じネットワークにいるかも確認してください |
| ポートが使われている | もう一度「▶ 起動」を押すと、空いているポートを自動で探します |
| 更新が見つからない | インターネットに接続できているか確認してください |

## 動作環境（目安）

- **Windows**: Windows 10 以降（x64）。Windows Server は、デスクトップ付きのインストールで動きます
- **macOS**: Apple Silicon / Intel
- **Linux**: Ubuntu 22.04 相当以上（x64）。デスクトップ環境と Tk が必要です
